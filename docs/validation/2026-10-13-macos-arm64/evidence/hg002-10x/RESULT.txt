Merge diagnostic observation
The final merge used 105 sort-reader and 105 decoder threads. In a bounded
one-second sample, most sort threads were waiting in semaphores or file IO.
A nearby process snapshot showed 0.1% CPU; a device-wide sample showed heavy
SSD traffic. Device activity alone does not attribute all IO to Bonefish.
The writer already has a 4-MiB buffer. The 17.89-minute merge is a concrete
output-pipeline target for a subsequent experiment with fewer simultaneous
run streams or a controlled APFS storage comparison. No such change was made
in this test. Any experiment must preserve decoded records and stable ties.
The run's elapsed timer includes the brief diagnostic sample.
