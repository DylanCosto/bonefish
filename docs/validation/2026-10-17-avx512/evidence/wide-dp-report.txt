AVX-512 wide DP: full 16-score tracking and guarded gap-state simplification

Complete wide-kernel speedup versus AVX2: 1.895913x in the six-batch comparison.
Actual-checkout confirmation: 1.882631x.
These are complete function timings, including allocation, initialization, H tracking and CIGAR traceback.
All 805 captured calls are included: 66 exact-tracking calls and 739 approximate-tracking calls.
The six-batch experiment alternates frozen old/new implementations; each batch has three alternating AVX2/512 trials with eight corpus repetitions, pinned to CPU23.

Changes:
Wide exact tracking processes complete 16-score blocks with unmasked AVX-512, preserving the original 8/4/scalar tails, range guard and tie keys.
For standard scoring and static bands, gap clipping uses max(a-(z+e),-(q+e)). This removes four vector subtracts per 64 cells. Other parameter combinations keep the original wrapping-byte expressions.
The fast arithmetic guard requires alphabet 5, match 2, mismatch -4, N score in [-4, 2], gap parameters 4/2/24/1 in either order, and safe static-band boundary arithmetic.
Eleven other selected source files are unchanged, including common traceback, narrow/register kernels, chaining, sorting and global SIMD caps.

Correctness:
183 tests passed, 0 failed, 6 ignored; no AVX-512 skips.
The complete 805-call oracle checks every result/CIGAR field against AVX2. Additional active-lane assertions verify the state bounds, clipped values and all continuation masks against the original expressions. These assertions are disabled before timing.
All three original-input modes (default, forced AVX2, forced SSE) match 161,762 reads and SAM MD5 9bc7ff3e9f498cc1530b2b1d78c47e10.
Both full 10x modes (default, forced AVX2) match 1,849,881 reads and SAM MD5 b83f40cfc93284abbfed78bff76ca4e5.
All mapping runs use 24 threads, the same reads/reference/prebuilt index, and remove only @PG when hashing SAM.

Reproduction and limits:
Portable Rust 1.99.1 / GCC 15.3 release build, jemalloc, opt3, fat LTO, one codegen unit; no native/global AVX-512, PGO, tune or bootstrap flags.
Source reproduction uses base 6e39b586a68439a8d176aafd68a87f0a05fd9b88 plus patches 01 through 08. All 13 selected source files and every reproduced repository file match the actual tested checkout.
The theoretical 2x width ratio is not a whole-mapper guarantee. The measured approximately 1.9x result applies to the captured wide-DP workload on this VM.
VMware does not expose usable physical-cycle/frequency counters. Nominal 2 GHz is not a measured clock; no downclock conclusion is drawn.
